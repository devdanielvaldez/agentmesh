# Security policy

Security is a core product property of AgentMesh. Please do not disclose suspected vulnerabilities
in public issues, discussions, or pull requests.

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting** feature from the repository's Security tab. Include:

- affected version or commit;
- a concise impact assessment;
- reproduction steps or a proof of concept;
- any suggested mitigation;
- whether the report is subject to an embargo.

We aim to acknowledge complete reports within three business days and provide an initial assessment
within seven business days. Timelines may vary with severity and complexity. We will coordinate
disclosure and credit with the reporter.

## Supported versions

AgentMesh is pre-release software. Until the first stable release, only the latest commit on `main`
receives security fixes. Do not use the project to protect production credentials yet.

## Scope

Reports involving authentication bypass, cross-tenant access, credential leakage, SSRF, request
smuggling, policy bypass, malicious MCP metadata, or denial of service are especially valuable.
