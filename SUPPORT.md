# Support

AgentMesh is currently a pre-release open-source project maintained on a best-effort basis.

## Where to ask

- Use **GitHub Discussions** for questions, deployment ideas, and design conversations.
- Use the appropriate **issue template** for reproducible bugs or scoped feature requests.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never post them publicly.

## Before requesting help

Include the AgentMesh version or commit, operating system, Rust version, deployment method, relevant
configuration with secrets removed, expected behavior, actual behavior, and minimal reproduction
steps. Trace IDs and stable public error codes are useful; credentials and tool arguments are not.

## Support policy

Only the latest commit on `main` is supported until the first stable release. There is no commercial
support, guaranteed response time, or production SLA at this stage. Security reports follow the
separate response targets in [SECURITY.md](SECURITY.md).
